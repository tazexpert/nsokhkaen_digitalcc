# ระบบบริหารจัดการศูนย์ดิจิทัลชุมชน จังหวัดขอนแก่น

ระบบเว็บ PHP + MySQL สำหรับจัดเก็บข้อมูลศูนย์ดิจิทัลชุมชน ผู้ดูแลศูนย์ และกิจกรรม
พร้อมหน้าเว็บสาธารณะแสดงแผนที่และรายละเอียดแต่ละศูนย์

## คุณสมบัติ

**หลังบ้าน (`/admin`)**
- เพิ่ม / แก้ไข / ลบ ศูนย์ดิจิทัลชุมชน พร้อมกำหนดพิกัด lat/long โดยคลิกบนแผนที่ ลากหมุด ใช้ตำแหน่งปัจจุบัน หรือวางพิกัดจาก Google Maps
- ภาพหน้าปกศูนย์ และแกลเลอรีภาพศูนย์ (อัปโหลดหลายไฟล์ ใส่คำบรรยาย ลบได้)
- ผู้ดูแลศูนย์ (หลายคนต่อศูนย์): รูป ชื่อ ตำแหน่ง โทร อีเมล LINE รายละเอียด
- กิจกรรมที่จัดร่วมกับศูนย์: วันที่ ผู้จัด จำนวนผู้เข้าร่วม รายละเอียด ภาพหน้าปก และภาพกิจกรรมหลายภาพ
- หน้าภาพรวม (สถิติ จำนวนศูนย์ตามอำเภอ กิจกรรมล่าสุด) และจัดการผู้ใช้ / เปลี่ยนรหัสผ่าน
- ย่อรูปที่ใหญ่เกิน 1600px อัตโนมัติ (ต้องเปิด GD), ป้องกัน CSRF, SQL injection และห้ามรันสคริปต์ในโฟลเดอร์ uploads

**หน้าบ้าน**
- `digital.html` — หน้ารวม: สถิติ ค้นหา/กรองตามอำเภอและประเภท แผนที่ปักหมุดทุกศูนย์ (จัดกลุ่มหมุด) การ์ดศูนย์ และกิจกรรมล่าสุด
- `center.html?id=N` — หน้ารายละเอียดศูนย์: แผนที่ปักหมุด ปุ่มนำทาง Google Maps ภาพศูนย์ ผู้ดูแล และไทม์ไลน์กิจกรรมพร้อมภาพ (ดูภาพแบบ lightbox)

## การติดตั้ง

1. ต้องมี PHP 8.1+ (เปิด `pdo_mysql`, แนะนำ `gd`) และ MySQL 5.7+/MariaDB 10.3+
2. สร้างฐานข้อมูลและตาราง:
   ```bash
   mysql -u root -p < database/schema.sql
   ```
   นำเข้าข้อมูลศูนย์จริงปี 2569 (46 ศูนย์ พร้อมผู้ดูแล):
   ```bash
   mysql -u root -p < database/import_centers_2569.sql
   ```
   ไฟล์นี้รันซ้ำได้ (อ้างอิงรหัสศูนย์ ไม่สร้างข้อมูลซ้ำ) และใช้กับฐานข้อมูลเดิมที่ยังไม่มีคอลัมน์รหัสศูนย์ได้
   (ไม่บังคับ) ข้อมูลตัวอย่างสำหรับทดลอง: `database/sample_data.sql` — ไม่ต้องใช้ถ้านำเข้าข้อมูลจริงแล้ว
3. แก้ไขค่าการเชื่อมต่อใน `config.php` (หรือกำหนด environment `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`)
4. ให้เว็บเซิร์ฟเวอร์เขียนโฟลเดอร์ `uploads/` ได้ เช่น `chmod -R 775 uploads`
5. เปิด `http://your-host/admin/` แล้วเข้าสู่ระบบด้วย **admin / admin1234** — เปลี่ยนรหัสผ่านทันทีที่เมนู "บัญชีผู้ใช้"

ทดสอบบนเครื่องได้ด้วย `php -S localhost:8000` แล้วเปิด http://localhost:8000/digital.html

> ถ้าใช้ Nginx ให้ปิดการรัน PHP ในโฟลเดอร์ `uploads/` และห้ามเข้าถึง `includes/`, `database/` (ไฟล์ `.htaccess` ที่ให้มาใช้ได้กับ Apache เท่านั้น)

## โครงสร้างไฟล์

```
digital.html        หน้ารวมศูนย์ (หน้าบ้าน)
center.html         หน้ารายละเอียดศูนย์
api/centers.php     JSON API (อ่านอย่างเดียว) ที่หน้าบ้านเรียกใช้
admin/              ระบบหลังบ้าน
includes/           ฟังก์ชันกลาง การเชื่อมต่อฐานข้อมูล รายชื่ออำเภอ
database/           schema.sql และข้อมูลตัวอย่าง
assets/             CSS / JS
uploads/            ไฟล์ภาพที่อัปโหลด (centers, staff, activities)
config.php          ตั้งค่าระบบ
```
